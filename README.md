# 🌿 하늘양식 QT (나만의 말씀묵상 반응형 웹 앱)

외부 서버나 클라우드로 데이터가 전혀 전송되지 않고, **오직 내 기기(스마트폰·PC 브라우저) 내부에만 저장되는 개인 맞춤형 말씀묵상(QT) 웹 앱**입니다.

---

## ✨ 주요 기능

1. **오늘의 말씀 본문 & 4단계 묵상 노트 (`오늘의 QT` 탭)**
   - 날짜별 성경 본문 및 묵상 길잡이 질문 제공
   - 마음에 와닿는 구절 터치 시 **형광펜(하이라이트) 저장**
   - 교회 주보나 개인 QT 책 본문을 쓰고 싶을 때 **본문 직접 입력/수정** 가능
   - **관찰(Observation) · 느낌/묵상(Meditation) · 적용(Application) · 기도와 감사(Prayer)** 4단계 노트 작성 및 자동 저장
   - 오늘 결단한 적용을 실제로 행했는지 체크하는 **적용 실천 완료(`✨`) 체크박스**

2. **묵상 캘린더 & 연속 달성 스트릭 (`묵상 캘린더` 탭)**
   - **연속 묵상 일수(🔥 Streak)**, **이번 달 묵상 횟수**, **총 누적 묵상**, **적용 실천율(%)** 자동 계산
   - 월별 달력에서 묵상 완료일(`🌿`)과 적용 실천 완료일(`🌿✨`) 스탬프 표시
   - 달력의 날짜를 누르면 해당 날짜의 말씀과 내가 적은 묵상 노트를 바로 확인·수정

3. **나의 묵상 기록장 (`기록장` 탭)**
   - 지금까지 작성한 모든 묵상 노트를 최신순으로 모아보기
   - 본문 장절, 제목, 묵상 키워드, 기도 내용으로 실시간 검색

4. **완벽한 기기 단독 보관 & 암호 잠금 (`기기 보안` 탭)**
   - **다른 기기/외부 열람 원천 차단**: 서버 DB를 사용하지 않고 기기 내 브라우저 저장소(`localStorage`)만 사용하므로 다른 곳에서는 절대 볼 수 없습니다.
   - **4자리 PIN 암호 잠금**: 내 스마트폰이나 PC를 타인이 열더라도 비밀번호 없이는 앱 화면을 볼 수 없도록 잠글 수 있습니다.
   - **백업 파일 내려받기/불러오기 (`.json`)**: 기기를 바꿀 때만 본인이 직접 파일로 내보내어 새 기기로 옮길 수 있습니다.
